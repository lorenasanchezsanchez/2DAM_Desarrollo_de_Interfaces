6.3.1. Construir la pantalla

En aquesta primera lliçó muntarem la pantalla sense programar encara cap acció. Primer repartirem l’amplada entre els jugadors i la franja central; després farem una targeta reutilitzable i hi col·locarem els controls.

Preparació. Imports i funcions que farem servir

Continuem en el projecte creat en 6.1. Obri el fitxer App.kt que ja has editat en 6.2, dins de shared/src/commonMain/kotlin/<paquet>/. En aquesta pràctica afegirem Comptador() al mateix fitxer i canviarem App() perquè el mostre. Conserva la línia package i no crees un segon composable App(). Android Studio pot afegir cada import automàticament quan el poses damunt del nom. Les classes principals són Row, Column, Card, FilledTonalButton i Text de Compose Material 3; Alignment alinea elements i Modifier descriu la mida i l’espaiat.

Abans de començar, canvia el contingut d’App() perquè mostre Comptador(). Mantín MaterialTheme i deixa els punts d’entrada d’Android i Desktop com estan:

@Composable
fun App() {
    MaterialTheme {
        Comptador()
    }
}

En aquesta pràctica, Comptador() és la pantalla que obrim des de App(). Afig la funció Comptador davall de App() en App.kt; en les pràctiques següents ampliarem el mateix projecte amb altres pantalles. Mantín els punts d’entrada d’Android i Desktop com estan.

En els exemples, Modifier.weight(1f) només es pot posar en un element fill d’una Row o Column. El número 1f vol dir “una part del pes total”, no un píxel ni una mida fixa. Si posem els pesos 1f, 0.34f, 1f, els dos jugadors ocupen una part semblant i la franja central és més estreta.

Els pesos són proporcions, no percentatges exactes: com que el centre té un pes més menut que cada jugador, ocupa menys amplada. No cal convertir-los a percentatges per a maquetar.

Pas 1. Preparar la finestra en tres zones

Primer comprovem només l’estructura exterior. En Comptador, posa dos textos de jugador i una columna central dins d’una Row:

@Composable
fun Comptador() {
    Row(Modifier.fillMaxSize().padding(16.dp)) {
        Text("JUGADOR 1", Modifier.weight(1f))
        Column(Modifier.weight(0.34f)) {
            Text("Controls")
        }
        Text("JUGADOR 2", Modifier.weight(1f))
    }
}

Executa Desktop i redimensiona la finestra. Row posa els tres elements en horitzontal; weight reparteix l’amplada disponible. Encara no hi ha targetes ni botons. Comprova que els dos jugadors ocupen espais semblants i que la zona central és més estreta.

Pas 2. Convertir un jugador en targeta

Abans de repetir-la, encapsulem una única targeta. Afig aquest composable al mateix fitxer i, temporalment, substitueix el primer Text del pas anterior per TargetaJugador(1, Modifier.weight(1f)):

@Composable
fun TargetaJugador(numero: Int, modifier: Modifier = Modifier) {
    Card(modifier = modifier.fillMaxHeight()) {
        Column(
            Modifier.fillMaxSize().padding(16.dp),
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.Center
        ) {
            Text("JUGADOR $numero")
            Text("20", fontSize = 32.sp, fontWeight = FontWeight.Bold)
        }
    }
}

Executa i comprova una targeta amb el nom i el valor inicial. numero permet reutilitzar la mateixa funció per a qualsevol jugador; modifier deixa que el pare decidisca quina part de la finestra ocupa.

Pas 3. Repetir la targeta i afegir la franja central

Ara reemplaça els tres fills de la Row —la primera targeta, la columna central i el text de J2— per aquest bloc complet. Ja inclou les dues targetes; no conserves els elements antics de la Row:

TargetaJugador(1, Modifier.weight(1f))
Column(
    modifier = Modifier.weight(0.34f).fillMaxHeight(),
    verticalArrangement = Arrangement.Center
) {
    FilledTonalButton(onClick = {}, modifier = Modifier.fillMaxWidth()) {
        Text("P1 ← P2")
    }
    FilledTonalButton(onClick = {}, modifier = Modifier.fillMaxWidth()) {
        Text("P1 → P2")
    }
}
TargetaJugador(2, Modifier.weight(1f))

Executa i comprova que els dos jugadors apareixen a banda i banda dels botons. Els clics no fan res encara.

Pas 4. Afegir els controls de vida a cada targeta

Modifica només el contingut de TargetaJugador: canvia la Column interior per una Row amb el botó de sumar, el marcador i el botó de restar.

Row(
    modifier = Modifier.fillMaxSize().padding(12.dp),
    horizontalArrangement = Arrangement.spacedBy(8.dp),
    verticalAlignment = Alignment.CenterVertically
) {
    FilledTonalButton(onClick = {}, modifier = Modifier.weight(1f).fillMaxHeight()) {
        Text("♥", color = Color.Red)
    }
    Column(
        modifier = Modifier.weight(3f),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Text("JUGADOR $numero")
        Text("20", fontSize = 32.sp, fontWeight = FontWeight.Bold)
    }
    FilledTonalButton(onClick = {}, modifier = Modifier.weight(1f).fillMaxHeight()) {
        Text("♡", color = Color.Red)
    }
}

Els pesos interns 1f, 3f i 1f reparteixen l’ample de cada targeta entre els dos botons i el marcador. Els controls centrals i els cors continuen sense acció: ara només comprovem el disseny.

Comprova abans de seguir: apareixen dos jugadors, els cors i les fletxes centrals. Redimensiona la finestra. fillMaxSize i fillMaxHeight ocupen l’espai ofert pel pare, sense fixar una mida en píxels.
