6.3.3. Afegir els verins

Les vides ja canvien i es poden transferir. Ara ampliarem el mateix patró amb un segon comptador per jugador: primer passarem l’estat del verí a les targetes i després hi afegirem els controls P+ i P−.

Pas 7.1. Preparar i passar l’estat de verí

Només quan les vides funcionen, afegim un altre comptador per jugador. El verí també és un nombre enter; per tant, podem usar el mateix mutableIntStateOf i el mateix mecanisme d’actualització.

Primer, dins de Comptador(), al costat de vides1 i vides2, declara els dos estats nous:

var verins1 by remember { mutableIntStateOf(0) }
var verins2 by remember { mutableIntStateOf(0) }

Després, modifica només la capçalera del TargetaJugador que ja tens. Afig verins just després de vides, i les dues funcions noves després de onRestar:

verins: Int,
onAfegirVeri: () -> Unit,
onLlevarVeri: () -> Unit,

Finalment, en les dues crides a TargetaJugador de Comptador(), afig el valor i les accions del jugador corresponent. Les vides i els verins tenen variables separades:

TargetaJugador(
    numero = 1,
    vides = vides1,
    verins = verins1,
    onSumar = { vides1++ },
    onRestar = { vides1-- },
    onAfegirVeri = { verins1++ },
    onLlevarVeri = { verins1-- },
    modifier = Modifier.weight(1f)
)

TargetaJugador(
    numero = 2,
    vides = vides2,
    verins = verins2,
    onSumar = { vides2++ },
    onRestar = { vides2-- },
    onAfegirVeri = { verins2++ },
    onLlevarVeri = { verins2-- },
    modifier = Modifier.weight(1f)
)

Comprova: ara el projecte torna a compilar i la pantalla encara es veu com abans. Ja hem passat els valors del verí; encara falta dibuixar-ne els controls.

Pas 7.2. Col·locar P+ i P− al costat dels cors

Per a fer lloc als nous controls, reemplaça el contingut de la Row de TargetaJugador pel bloc complet següent. Conserva el nom del jugador i el marcador al centre; a cada costat hi ha una columna amb el control de verí menut i el cor més gran:

Row(
    modifier = Modifier.fillMaxSize().padding(12.dp),
    horizontalArrangement = Arrangement.spacedBy(8.dp),
    verticalAlignment = Alignment.CenterVertically
) {
    Column(
        modifier = Modifier.weight(1f).fillMaxHeight(),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        FilledTonalButton(
            onClick = onAfegirVeri,
            modifier = Modifier.fillMaxWidth().weight(1f)
        ) { Text("P+") }
        FilledTonalButton(
            onClick = onSumar,
            modifier = Modifier.fillMaxWidth().weight(4f)
        ) { Text("♥", color = Color.Red) }
    }
    Column(
        modifier = Modifier.weight(3f).fillMaxHeight(),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        Text("JUGADOR $numero")
        Text("$vides / $verins", fontSize = 32.sp, fontWeight = FontWeight.Bold)
    }
    Column(
        modifier = Modifier.weight(1f).fillMaxHeight(),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        FilledTonalButton(
            onClick = onLlevarVeri,
            enabled = verins > 0,
            modifier = Modifier.fillMaxWidth().weight(1f)
        ) { Text("P-") }
        FilledTonalButton(
            onClick = onRestar,
            enabled = vides > 0,
            modifier = Modifier.fillMaxWidth().weight(4f)
        ) { Text("♡", color = Color.Red) }
    }
}

Les columnes laterals tenen el mateix pes 1f; el marcador central en té 3f. Dins de cada costat, els pesos 1f i 4f fan que el control de verí siga més menut que el cor. Ja estàs passant onAfegirVeri i onLlevarVeri des del pas 7.1, així que no cal canviar de nou les crides a TargetaJugador.

enabled desactiva P− o el cor buit quan el valor ja és zero. És el mateix paràmetre que hem usat en les fletxes centrals; no cal afegir cap comprovació dins de les funcions d’acció.

Les captures mostren l’estat visible després de cada etapa; no són una especificació d’una API d’Android. Tot el codi de pantalla d’aquests passos són composables comuns de Kotlin i Compose. Desktop executa la interfície en una finestra, i Android la mostra des de la seua Activity.

Comprova: cada jugador té vides i verins independents; els cors canvien la vida pròpia; P+ i P− canvien el verí; les fletxes centrals transfereixen una vida. Redimensiona la finestra i comprova que cap control desaparega. Després continua amb la Filmoteca.
